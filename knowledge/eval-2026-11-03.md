## Defects found and fixed

- GitHub's `gh --json` returns `subIssues`, `blockedBy`, and `blocking` as
  `{nodes,totalCount}` objects, not arrays. The provider now normalizes both
  shapes.
- A Feature branch could be stale after its Task PR merged remotely. Feature
  publishing now fetches and fast-forwards the local Feature branch before
  creating the integration worktree.
- The TUI/CLI now exposes `tools_registered` in the event log for diagnosing
  missing tool surfaces.
