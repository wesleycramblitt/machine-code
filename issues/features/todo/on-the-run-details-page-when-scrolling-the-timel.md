On the run details page, when scrolling the timeline, you can hit "Enter" to focus and expand a section. When doing this, the j/k commands to move the cursor work only in that section. We should do a smarter system, j/k should just move down through the sections, instead of at timestamps, it moves on each visible line (keeping an indicator where you can easily see where it is). So, for an input section, you may only see 5 lines when it isn't expadned, the cursor would go from the timestamp and header of the input, down through those 5 lines one at a time. If the user hit's "Enter", the section expands, and now the cursor can move through the entire section. Once reaching the end, it keeps going to the next timestamp as the user hits "j". So, basically, whatever lines are visible in the TUI, are what are scrolled by j/k. Enter just expands and collapses the lines.
